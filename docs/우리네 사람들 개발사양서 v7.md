## 1. 핵심 설계 원칙 (불변, v4와 동일)

> "역사는 단순하지 않다 — 그러나 불은 여전히 누군가 질렀다."

설계 가드레일: 사보타주 미화 금지 / 단심의 표적은 혈통이 아닌 구조·제국 / 단심은 학생의 선택에 의해서만 흔들림 / 엔딩A는 해피엔딩처럼 보이지 않게 / 새 기믹 금지.

## 2. 우화 대응표

| 게임 요소 | 상징 |
|---|---|
| 황재국 | 일본 제국주의(방화=원죄) |
| 황양선 | 양심적 지식인·기록자(침묵의 체념) |
| 황무진 | 현재의 일본인(무지→앎) |
| 조노을 | 조선(회상 전용) |
| 황찬일(조찬일) | 친일 한국인 — 가해자와의 동일시 |
| 황단심(조단심) | 독립운동가 — 저항하나 윤리적 얼룩 |
| 동양그룹 | 일본 제국(국가) |
| AI 복합센터 | 신제국주의(연산자원 차별) |

## 11. 에셋 체크리스트 및 이미지 사양

### 11-1. 이미지 구현 원칙

이 게임은 짧은 기한 내 Codex로 제작할 프로토타입이므로, 이미지 에셋은 다음 우선순위를 따릅니다.

1. **게임 진행 가능성 우선** — 모든 장면은 이미지 파일이 없어도 placeholder 또는 Phaser Graphics 대체로 정상 실행되어야 합니다.
2. **파일명 고정** — 나중에 고품질 이미지로 교체할 수 있도록 assetKey와 fileName은 고정합니다.
3. **단서 가독성 우선** — 다음 이미지는 반드시 텍스트가 읽히는 형태로 제작합니다: 벽 메시지, 경찰 탐문지, 검열 보고서, 양선 공책, PC 퍼즐, 설계도, 일기, 신분카드 복제 프로그램 실행 로그, 메모① 동기, 메모② 무감각.
4. **캐릭터 placeholder 규칙** — 고품질 일러스트가 없을 경우, 인물 이름과 감정 상태가 크게 적힌 SVG placeholder를 생성합니다. 예: "황단심 / 밝음", "황단심 / 무표정", "황찬일 / 최종".
5. **배경 placeholder 규칙** — 장소명과 분위기가 보이는 단색 또는 간단 도형 배경을 생성합니다. 예: "M2_Site / 잿빛 공사장", "M3_2_YangseonGarden / 노을빛 원예실".
6. **fallbackType 규칙** — 모든 이미지 항목은 다음 중 하나의 fallbackType을 가집니다.
   - `svg_placeholder`: Codex가 단순 SVG 파일 생성
   - `phaser_graphics`: Phaser Graphics로 즉석 렌더링
   - `css_ui`: HTML/CSS 또는 Phaser Text/Rectangle로 UI 대체
   - `text_panel`: 핵심 텍스트를 보여주는 문서형 패널로 대체
   - `reused_asset`: 기존 에셋 재사용
7. **code_only 컨벤션** — fileName이 `code_only`인 항목(예: fx_screen_shake, fx_typing_text, fx_folder_open)은 preload 대상 파일이 없으며, 해당 효과는 씬 코드에서 Phaser Tween/Graphics로 직접 구현합니다. assetManifest 로더는 이 항목을 건너뜁니다.

### 11-2. 에셋 폴더 구조

```text
src/assets/
├── characters/      # 대화용 캐릭터 일러스트
├── sprites/         # 탑뷰 캐릭터 스프라이트
├── backgrounds/     # 장면 배경, 엔딩 배경
├── tilesets/        # 탑뷰 맵 타일
├── objects/         # 단서, 문서, PC, 책, 도시락통 등
├── ui/              # 대화창, 수첩, 선택지, 작성창, 잠금화면
└── effects/         # glow, red overlay, fire, fade, speech bubble
```

Codex는 위 폴더가 없으면 자동 생성합니다.

### 11-3. Asset Manifest 구조

`src/data/assetManifest.js`를 신설합니다.

```js
export const ASSET_MANIFEST = [
  {
    key: 'char_mujin_default',
    fileName: 'characters/mujin_default.svg',
    category: 'character',
    useScenes: ['M1_1_MujinOffice', 'M3_Exterior'],
    required: true,
    fallbackType: 'svg_placeholder',
    description: '황무진 기본 대화 일러스트. 단정한 정장, 젊음, 미소 뒤 긴장감.'
  }
];
```

필드 정의:

| 필드 | 의미 |
|---|---|
| key | Phaser `load.image`에 사용할 고유 키 |
| fileName | `src/assets/` 이하 상대 경로. `code_only`면 실제 파일 없음(11-1-7 참조) |
| category | character / sprite / background / tileset / object / ui / effect |
| useScenes | 사용되는 canonical sceneId 배열(§3 기준, state는 별도 구분하지 않고 sceneId 단위로 기재). 반복·전역 에셋은 아래 예약어 사용 가능 |
| required | true면 반드시 preload 대상(누락 시 §11-11 fallback 필수) |
| fallbackType | svg_placeholder / phaser_graphics / css_ui / text_panel / reused_asset |
| description | placeholder 생성 시 참고할 설명 |

`useScenes` 예약어:

| 예약어 | 의미 | 처리 방식 |
|---|---|---|
| `__ALL_EXPLORATION__` | 모든 탑뷰 탐색 씬 | AssetLoader에서 전역 preload하거나 §3의 탐색 씬 목록으로 확장 |
| `__ALL_DIALOGUE__` | 모든 대화 씬 | 전역 UI 에셋으로 preload |
| `__NOTEBOOK_ENABLED__` | 수첩 해금 이후 수첩 사용 가능 씬 | 전역 UI 에셋으로 preload하고 `notebook_unlocked=true` 이후 표시 |
| `__CLUE_OR_PERSON_UPDATE__` | 단서·인물 갱신 토스트가 발생하는 씬 | 전역 UI 에셋으로 preload |
| `__INTERACTIVE_OBJECT_SCENES__` | 상호작용 가능 오브젝트가 있는 씬 | 전역 effect 에셋으로 preload |

§11-4~§11-9의 모든 에셋 표는 `category` 열을 각 행에 직접 포함합니다. Codex는 표 제목이 아니라 각 행의 `category` 값을 기준으로 `assetManifest.js`를 생성해야 합니다.

1. `src/data/assetManifest.js`를 읽어 모든 이미지를 preload합니다.
2. 실제 파일이 없으면 `src/utils/createPlaceholderAssets.js`에서 fallback을 생성합니다.
3. fallback SVG는 빌드 전에 `src/assets/...` 경로에 생성하거나, 런타임에서 Phaser texture로 등록합니다.
4. placeholder에는 반드시 다음 정보가 눈에 보여야 합니다: assetKey / 장면명 또는 사용 장소 / 인물명·오브젝트명 / 감정 상태 또는 핵심 텍스트.
5. 텍스트 단서형 이미지는 `text_panel` fallback을 우선합니다.
6. UI 이미지는 css_ui 또는 Phaser Rectangle/Text로 대체 가능합니다.
7. 이미지 로드 실패 때문에 씬 전환이 멈추면 안 됩니다.
8. `required: true` 에셋은 누락되어도 fallback으로 반드시 등록합니다.
9. `required: false` 에셋은 누락되어도 경고만 남기고 진행합니다.
10. 모든 fallback은 추후 같은 fileName의 실제 이미지로 교체 가능해야 합니다.

```js
export function getFallbackAsset(asset) {
  switch (asset.fallbackType) {
    case 'svg_placeholder':
      return createSvgPlaceholder(asset.key, asset.description);
    case 'text_panel':
      return createTextPanelSvg(asset.key, asset.description);
    case 'css_ui':
      return null; // UI 컴포넌트에서 CSS/Phaser 객체로 대체
    case 'phaser_graphics':
      return null; // 씬에서 graphics로 직접 그림
    case 'reused_asset':
      return asset.reuseFrom;
    default:
      return createSvgPlaceholder(asset.key, asset.description);
  }
}
```

### 11-12. 절대 만들지 않을 이미지

1. **탐정 대화용 얼굴 일러스트** — 탐정은 1인칭 화자이므로 화면에 등장하지 않습니다. 단, 탑뷰 이동용 `spr_player`는 필요합니다.
2. **단심 구속 일러스트** — EndingA에서는 단심이 목소리만 나옵니다. 암전 처리로 충분합니다.
3. **작성3 UI** — 작성3은 게임 내부가 아니라 디브리핑 워크시트에서 진행합니다.
4. **PC 퍼즐 힌트 버튼** — 수첩의 ★ 주제문이 힌트 역할을 하므로 별도 힌트 UI를 만들지 않습니다.
5. **메모 조각 3·4** — 2막 v2.1 기준 메모는 2개뿐입니다.

## 12. 오디오 사양 — audioManifest.js / AudioSystem.js

### 12-1. 오디오 구현 원칙

이 게임의 오디오는 이미지보다 우선순위가 낮습니다. 내일까지의 프로토타입 구현과 7월 10일 이후 실제 수업 사용을 모두 고려하여, v7에서는 **12개 최소 음원안**만 정식 구현 대상으로 삼습니다.

1. **음원 누락 허용** — 모든 오디오 에셋은 `required: false`입니다. 파일이 없어도 게임 진행이 멈추면 안 됩니다.
2. **BGM 4종 + SFX 8종으로 제한** — 장면별 세부 BGM과 환경음(AMB)은 v7 구현 대상에서 제외합니다.
3. **감정 과잉 금지** — 음악이 학생의 윤리적 판단을 대신 유도하지 않도록, 낮은 볼륨과 건조한 분위기를 기본값으로 합니다.
4. **EndingA 무음 원칙** — EndingA는 BGM을 아주 작게 시작한 뒤 fadeOut하고, 마지막은 반드시 무음 정적으로 유지합니다.
5. **파일명 고정** — 추후 실제 음원을 구하거나 제작하면 같은 fileName으로 교체합니다.
6. **fallback 우선** — BGM 파일이 없으면 `silence`, SFX 파일이 없으면 WebAudio 기반 `generated_click`, `generated_error`, `generated_noise_hit` 등으로 대체할 수 있습니다.
7. **환경음 제외** — v7에서는 `amb_*` 계열 환경음을 만들지 않습니다. 장소감은 BGM과 텍스트/이미지 연출로 처리합니다.

### 12-7. AudioSystem 구현 규칙

`src/systems/AudioSystem.js`를 신설합니다.

필수 기능:

1. `AUDIO_MANIFEST`를 preload 대상으로 등록합니다. 단, 모든 항목은 `required:false`이므로 파일이 없어도 오류로 중단하지 않습니다.
2. `playBgm(key, options)`는 기존 BGM을 fadeOut하고 새 BGM을 fadeIn합니다.
3. 같은 BGM이 이미 재생 중이면 다시 시작하지 않습니다.
4. `stopBgm({ fadeOutMs })`로 EndingA 무음 처리를 구현합니다.
5. `playSfx(key)`는 파일이 있으면 파일을 재생하고, 없으면 fallback을 실행합니다.
6. `setBgmVolume(volume, durationMs)`로 유가족 장면, 찬일 final, EndingA 등에서 볼륨을 낮춥니다.
7. 브라우저 정책상 첫 사용자 입력 전 오디오가 자동 재생되지 않을 수 있으므로, 첫 클릭/키 입력 이후 AudioSystem을 unlock합니다.
8. 음소거 토글을 제공해 수업 환경에서 즉시 끌 수 있게 합니다.
9. 오디오 로드 실패는 console.warn만 남기고 게임 흐름을 계속합니다.

예시:

```js
export class AudioSystem {
  constructor(scene) {
    this.scene = scene;
    this.currentBgmKey = null;
    this.currentBgm = null;
    this.enabled = true;
    this.unlocked = false;
  }

  playBgm(key, { volume = 0.3, fadeInMs = 800, fadeOutMs = 800 } = {}) {
    if (!this.enabled || this.currentBgmKey === key) return;
    this.stopBgm({ fadeOutMs });
    if (!this.scene.cache.audio.exists(key)) return;
    const bgm = this.scene.sound.add(key, { loop: true, volume: 0 });
    bgm.play();
    this.scene.tweens.add({ targets: bgm, volume, duration: fadeInMs });
    this.currentBgm = bgm;
    this.currentBgmKey = key;
  }

  playSfx(key) {
    if (!this.enabled) return;
    if (this.scene.cache.audio.exists(key)) {
      this.scene.sound.play(key);
      return;
    }
    this.playGeneratedFallback(key);
  }

  stopBgm({ fadeOutMs = 800 } = {}) {
    if (!this.currentBgm) return;
    const bgm = this.currentBgm;
    this.scene.tweens.add({
      targets: bgm,
      volume: 0,
      duration: fadeOutMs,
      onComplete: () => bgm.stop()
    });
    this.currentBgm = null;
    this.currentBgmKey = null;
  }
}
```

### 12-8. fallbackType 정의

| fallbackType | 의미 | 구현 방식 |
|---|---|---|
| silence | 음원 파일이 없으면 아무 소리도 내지 않음 | no-op |
| generated_click | 짧은 클릭음 | WebAudio oscillator 또는 Phaser sound 대체 |
| generated_error | 짧고 낮은 오류음 | 낮은 주파수 oscillator |
| generated_noise_hit | 짧은 노이즈/충격음 | noise buffer 또는 매우 짧은 저음 톤 |

주의: fallback 생성음은 최소한으로만 사용합니다. 생성음이 거슬리면 즉시 `silence`로 바꿀 수 있어야 합니다.

### 12-9. v7에서 만들지 않을 오디오

1. **환경음 AMB 전체** — v7 구현 대상에서 제외합니다.
2. **장면별 세분화 BGM** — 본사/찬일/공사장/서재/원예실 등을 각각 따로 만들지 않습니다. BGM 4종으로 통합합니다.
3. **대사 타이핑음** — 반복 피로가 크므로 제외합니다.
4. **선택지 이동음** — 선택 확정음 `sfx_confirm`만 사용합니다.
5. **수첩 열기/닫기 별도음** — `sfx_clue` 또는 무음으로 처리합니다.
6. **EndingA 전용 고급 BGM** — `bgm_final_pressure`를 아주 작게 사용한 뒤 무음 처리합니다.
7. **작성3 관련 오디오** — 작성3은 게임 외부 디브리핑 워크시트 대상이므로 오디오도 만들지 않습니다.

## 17. 최종 권고

**Codex 투입 가능합니다.** 1막 대본 v3.1 / 2막 대본 v2.1 / 본 사양서 v7의 scene·flag·clue·quest·essay ID, 이미지 asset 구조, 오디오 asset 구조가 전부 일치하며, 본문(대사·내레이션·연출)은 어느 문서에서도 변경되지 않았습니다.

보류 권장 사항(구현 전 결정이 더 필요한 것, 본 패치 범위 밖):
- §3에서 미채택한 `IdentityScene`처럼, 추후 정체 공개 시점을 별도 컷신으로 분리하고 싶다면 새 씬 추가 여부를 별도로 논의해야 합니다(현재는 M1_2(2nd) 내부 처리로 충분).
- §15 디브리핑 워크시트 자체(우화 대응표 공개 자료, 작성3 실제 운영 방식)는 아직 별도 문서로 만들어지지 않았습니다 — 본 사양서는 "게임 데이터에도, 에셋에도 포함하지 않는다"는 경계만 확정했습니다.
- 실제 이미지(고품질 일러스트·배경)는 §11-1의 placeholder 우선 원칙에 따라, 실제 사운드는 §12의 required:false/fallback 원칙에 따라 추후 별도로 제작·교체합니다. 사운드는 §12의 12개 최소 오디오안으로 우선 구현하며, 실제 음원 파일은 추후 동일 fileName으로 교체 가능합니다.
